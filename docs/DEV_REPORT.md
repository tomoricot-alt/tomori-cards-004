# 開発レポート — TOMORI CARDS (APP 004)

## 実装内容
- 4画面（ホーム／カード登録・編集／暗記学習／学習結果）、画面遷移はstate管理
- セット・カードのCRUD、シャッフル（Fisher-Yates）、覚えた/もう一度の記録、進捗%、まちがい復習
- 保存: Web=localStorage、ネイティブ=AsyncStorage。保存データは読み込み時に検証し、不正な要素は破棄
- 入力検証: 空・空白のみ拒否、文字数上限（セット名30／カード各200）、制御文字除去、セット50個・1セット1000枚の上限
- データ消失の注意をホームに常時表示。保存失敗・データ破損時は警告を表示
- カードめくりは Animated の rotateY（web は JS ドライバ、ネイティブは native driver）
- デザイン: アイボリー背景、青・紫アクセント、大きな文字、PC幅は中央640px
- GitHub Actions: PRで型チェック・テスト・Webビルド、mainマージ後にPages自動公開
- 参考リポジトリ（tomori-focus-001）はこのセッションからアクセスできなかったため参照していません
