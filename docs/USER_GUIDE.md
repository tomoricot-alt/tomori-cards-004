# TOMORI CARDS の使い方

暗記したいことを「カード」にして、くり返し覚えるアプリです。

## 1. セットを作る
1. ホームの「＋ 新しいカードセットを作る」を押す
2. 教科（英語・歴史・理科…）を選び、セット名（例：中2 英単語）を入れて「作成する」

## 2. カードを入れる
1. セットをタップして「カード編集」画面を開く
2. **表面**に問題（例：apple）、**裏面**に答え（例：りんご）を入れて「カードを追加」
3. まちがえたら「編集」「削除」でなおせます

## 3. 覚える
1. ホームで「学習する」を押す
2. カードをタップすると、くるっとめくれて答えが見えます
3. 覚えていたら「覚えた！」、あやしかったら「もう一度」
4. 「🔀 シャッフル」で順番をまぜられます

## 4. 結果を見る・復習する
- 終わると、覚えた数と全体の進捗(%)が出ます
- 「まちがえたカードを復習」で、「もう一度」にしたカードだけをやり直せます

## ⚠️ 大事なこと
- カードは**このスマホ／パソコンのブラウザの中だけ**に保存されます
- ブラウザの「閲覧データの削除」をすると**カードが消えます**
- 別の端末や別のブラウザでは同じカードは見られません
- 名前・学校名・メールアドレスなどは入れないでください（求められることもありません）
- 広告や外部リンクはありません
